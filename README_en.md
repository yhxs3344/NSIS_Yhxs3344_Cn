# NSISBI ZH-CN

**Language:** [简体中文](README.md) · [English](README_en.md)

> **NSIS (Nullsoft Scriptable Install System) is an open-source software tool for creating installers on the Windows operating system. It provides functionalities such as installation, uninstallation, system configuration, and file decompression. As its name suggests, NSIS describes the behavior and logic of an installer through its own scripting language. The NSIS scripting language shares structural and syntactical similarities with general-purpose programming languages, but it is specifically designed for installer-oriented applications.
> Based on the official NSIS v3.12 release and jasonfriday13's nsisbi v3.12.3, this is a recompiled version with localized Chinese translations.
