19/03/2020 - 7140-2

- More improvements on 32bit linux
  Some 32bit distros, ubuntu in particular, hardcode _FILE_OFFSET_BITS to 32 bit, and force use of
  64bit specific calls instead, which means setting _FILE_OFFSET_BITS has no effect.
  So the improvement is to use a helper instead, which checks for _LARGEFILE64_SOURCE and
  uses those calls if they are available first, and if not available falls back to standard calls.
